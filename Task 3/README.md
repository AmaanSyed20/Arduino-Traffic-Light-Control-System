# Task 3 · Vehicle Signal on a Breadboard

This task takes the timed vehicle signal from [Task 1](../Task%201/) onto a physical breadboard. The recording shows the Arduino connected by jumper wires to the red, yellow and green LEDs.

[Watch the breadboard demonstration](./Task%201%20Implementation.mp4)

## Reading the demonstration

In the sketch, red and yellow light together immediately before green. Yellow lights on its own after green. These two patterns make it easier to identify which part of the sequence the controller is running.

The clip lasts approximately 11 seconds and captures part of the programmed 13-second cycle. The [Task 1 sketch](../Task%201/Code.ino) gives the full sequence, pin assignments and timing for each phase.
