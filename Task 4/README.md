# Task 4 · Pedestrian Crossing on a Breadboard

This task brings the [Task 2 pedestrian-crossing design](../Task%202/) onto a breadboard. The prototype combines a push-button input with separate LEDs for the vehicle and pedestrian signals.

[Watch the pedestrian-crossing demonstration](./Task%202%20Implementation.mp4)

## Following a crossing request

The approximately 26-second clip shows the physical prototype. To follow the intended sequence, watch the two signals together. After a request, the vehicle signal passes through yellow to red. Both signals stay red briefly before the pedestrian signal turns green. At the end of the crossing phase, pedestrian red returns before the vehicle signal changes to red and yellow, then green.

The [Task 2 state diagram](../Task%202/Class%20Diagram%20%26%20State%20Machine%20Diagram.png) gives the design timing for each transition. The hardware recording documents the build as part of the ongoing lab project.
